# Security policy

## Supported versions

Security fixes target the latest JL-Mod Plus release and the current `dev` branch. Older builds may not receive backports.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability reporting feature for `H3nb/JL-Mod-Plus` and include:

- the affected version or commit;
- device and Android version when relevant;
- reproduction steps or a proof of concept;
- expected impact;
- any suggested mitigation.

Do not include real user data, signing keys, credentials, proprietary games, or other secrets. H3NB coordinates release decisions and public disclosure. This hobby project cannot promise a formal response SLA, but good-faith reports will be reviewed as time permits.
